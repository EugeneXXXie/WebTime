# Security

Security fixes target the latest source on the default branch. Older snapshots are not separately maintained.

For a vulnerability, use this repository's **Security → Advisories → Report a vulnerability** if private reporting is enabled. If that option is unavailable, open an issue asking the maintainer for a private reporting channel, without including exploit details or sensitive data.

Include the affected version, browser/OS, a minimal synthetic reproduction and expected impact. Never attach your real browsing backup, cookies, credentials or browser profile. Avoid publishing exploit details until the maintainer has had a chance to assess the issue.

Regular UI bugs and feature suggestions belong in Issues. Maintainers should enable private vulnerability reporting in GitHub repository settings before inviting public use.
